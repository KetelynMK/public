# 🏠 Grupo Assis — Serviços Residenciais

## 📌 Sobre o projeto

O **Grupo Assis** é um website institucional desenvolvido para apresentar serviços residenciais de forma moderna, organizada e responsiva.

O projeto foi pensado para facilitar o contato entre clientes e a empresa, permitindo visualizar os serviços disponíveis, conhecer melhor a empresa e solicitar informações ou orçamentos.

🌐 **Projeto online:**
https://grupo-assis.vercel.app/

---

## 🎯 Objetivo

O objetivo do projeto é criar uma presença digital profissional para uma empresa de serviços residenciais, apresentando suas soluções de maneira clara e proporcionando uma experiência simples para o usuário.

O site apresenta serviços como:

* 👵 Cuidados com idosos
* 🐶 Passeio com pets
* 🧹 Limpeza residencial
* 🧽 Limpeza profissional
* 👶 Cuidados infantis
* 🏠 Organização residencial
* 🌱 Jardinagem
* 📦 Organização de ambientes
* 🍽️ Limpeza de cozinha
* 👔 Passadoria
* 🧹 Limpeza pós-obra

Os serviços são apresentados em um **carrossel interativo**, permitindo que o usuário navegue pelas opções disponíveis.

---

## ✨ Funcionalidades

### 🏠 Página inicial

Apresentação da empresa com uma seção principal destacando:

> **Cuidado e qualidade**

Com botões de acesso rápido para conhecer os serviços e entrar em contato.

### 👥 Sobre nós

Seção institucional apresentando a proposta do Grupo Assis e seus principais valores:

* Responsabilidade
* Qualidade
* Confiança

### 🛠️ Serviços

Carrossel com diferentes serviços residenciais, permitindo navegar entre as opções utilizando setas ou arrastando os cards.

### 💰 Orçamento

Área destinada à solicitação de informações sobre valores e disponibilidade dos serviços.

Os preços são definidos de acordo com o serviço solicitado e as necessidades do cliente.

### 📞 Contato

Seção de contato com opções para atendimento por:

* Telefone
* WhatsApp
* Formulário de contato

O formulário permite informar nome, telefone e o tipo de ajuda necessária.

### 📱 Design responsivo

O layout foi desenvolvido pensando em diferentes tamanhos de tela, proporcionando uma experiência adequada em:

* 💻 Computadores
* 💻 Notebooks
* 📱 Smartphones
* 📲 Tablets
